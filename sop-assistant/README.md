# 制造业 SOP 知识助手｜求职作品集项目

> 当前版本：可浏览器本地运行的交互式产品原型（MVP v0.2）。场景、设备与文档均为模拟素材，仅用于作品集演示，不是任何真实工厂的生产建议。

## 项目目标

让一线操作员能按设备、工序和故障现象快速找到对应 SOP，并看到来源、适用条件和安全提醒；材料不充分时明确提示补充信息或联系主管，不编造维修步骤。

## 运行

直接打开 `index.html`。无需安装、无需联网。输入示例：

- `贴标机标签偏移怎么处理`
- `开机前需要检查什么`
- `安全门报警`
- `怎么提高产能`（应触发范围外提示）

也可点击左侧示例问题和“开始排查”。

## 目录

- `index.html`：交互式 Demo
- `产品方案.md`：用户、问题、方案、流程、PRD、指标与迭代计划
- `测试集与结果.md`：手工验收测试集与测试记录模板（结果需实际运行后填写）
- `assets/`：模拟 SOP 知识条目

本轮对 8 个问题做了浏览器脚本验收，并补充了常见问法别名；详细结果记录在 `测试集与结果.md`。该验收覆盖页面逻辑，不等同于真实用户测试或生产质量评估。

## MVP 边界

前端使用本地模拟检索与规则化回答，目的是演示产品流程、来源展示、拒答和安全交互；当前并未连接真实大模型、向量数据库或真实工厂资料。真实试点需要企业批准资料、权限控制、版本治理、后端检索服务和现场验证。
