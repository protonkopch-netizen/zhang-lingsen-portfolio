# 制造业 SOP 知识助手｜产品方案

## 1. 项目摘要

**产品定位：**面向制造现场的一线操作员和维修人员，提供带来源依据的标准作业与故障排查问答。

**核心价值假设：**在 SOP 分散、版本多、现场查找耗时的场景中，统一检索入口可能降低查找时间，并减少员工凭经验操作的风险。此价值目前是待验证假设，不是已实现的业务成果。

**目标用户：**产线操作员（主要使用者）、设备维修人员（复杂问题处理者）、工艺/设备主管（知识维护与审核者）。

## 2. 问题与假设

| 项目 | 当前假设 | 验证方式 |
|---|---|---|
| SOP 难找 | 文件分散在纸张、共享盘或群聊 | 访谈操作员/主管，记录查找路径和耗时 |
| 内容难懂 | 文档按章节组织，不按现场问题组织 | 收集真实问法，与文档标题对照 |
| 错用旧版本 | 多版本并存，员工不易识别生效版本 | 抽查资料版本和审批状态 |
| AI 可能答错 | 生成式回答可能无依据或遗漏安全条件 | 建立测试集，检查引用和拒答表现 |

> 作品集如无真实访谈，应注明“桌面研究/待验证假设”，不要声称已访谈真实工厂用户。

## 3. MVP 范围

### 包含

- 中文自然语言提问与问题示例。
- 按模拟知识条目匹配回答。
- 展示来源文件、章节、版本和适用设备。
- 对证据不足、范围外问题提示补充信息或联系主管。
- 对安全相关问题显示醒目的安全提示。
- 用户反馈“有帮助/没帮助”。

### 不包含

- 自动控制设备、自动下发工艺参数或自动执行维修。
- 无审核地生成新的安全操作步骤。
- 接入真实工厂账号、设备、MES/ERP 或企业文档。
- 宣称真实业务指标或已上线生产环境。

## 4. 核心用户流程

1. 用户选择设备或直接输入问题。
2. 系统识别问题主题，检索适用的 SOP 条目。
3. 有匹配依据时，按步骤呈现答案并展示引用及版本。
4. 涉及安全风险时先展示安全提示；缺少关键信息或无可靠依据时拒答并引导升级。
5. 用户反馈结果，维护人员依据反馈检查知识条目和问题分类。

## 5. 关键需求与验收标准

| ID | 需求 | 验收标准 |
|---|---|---|
| R1 | 输入现场问题 | 可输入中文并提交；可点击示例问题 |
| R2 | 展示步骤化答案 | 每条操作步骤清晰，避免混入无依据内容 |
| R3 | 展示来源 | 至少显示模拟文件名、章节、版本、设备 |
| R4 | 证据不足时拒答 | 不匹配问题显示“不在当前知识范围”，提示找主管/补充信息 |
| R5 | 安全提醒 | 安全门/急停/电气等条目显示“先停机并按现场安全流程处理”类提示，不鼓励带电操作 |
| R6 | 反馈闭环 | 有帮助/没帮助按钮可操作并显示反馈状态 |
| R7 | 响应体验 | 本地 Demo 应即时显示；真实系统需另定延迟目标并测量 |

## 6. 知识条目设计

每条文档记录建议包含：`doc_id`、设备、工序、主题、适用条件、问题别名、步骤、风险等级、安全提示、来源文件、章节、版本、生效日期、审核人、状态。

真实系统中，只检索已审核且当前生效的文档；旧版本可追溯但不参与默认回答。按文档切片时保留标题、步骤、警告和上下文关系，避免将安全条件与操作步骤拆散。

## 7. 技术方案（概念）

**当前 Demo：**浏览器本地 JavaScript + 模拟知识条目 + 关键词/标签匹配，不调用模型和外部服务。

**真实 PoC 可选架构：**文档解析与版本审核 → 分块/元数据 → 向量与关键词混合检索 → 重排 → 大模型按证据生成 → 引用校验/拒答策略 → 日志和人工反馈。

模型只负责把检索到的依据整理成易读回答；没有可靠检索结果时应拒答。生产系统还需企业身份权限、日志脱敏、文档访问控制、人工审核及安全评审。

## 8. 效果评估

先建立标注测试集，记录每题的标准答案要点、适用文档、风险等级和是否应该拒答。建议追踪：

- **检索命中率：**正确依据是否出现在候选结果中。
- **引用准确率：**回答引用是否确实支持对应结论。
- **答案要点覆盖率：**必要步骤和条件是否完整。
- **拒答正确率：**无依据/范围外问题是否被正确拦截。
- **安全用例通过率：**高风险问题是否展示安全提示并避免危险建议。
- **现场效率：**真实试点中任务查找时间的前后变化。
- **采用与满意度：**使用率、反馈率、主管审核意见。

没有实测前不填“提升 xx%”；测试记录见 `测试集与结果.md`。

## 9. 迭代路线

| 阶段 | 目标 | 交付 |
|---|---|---|
| MVP | 验证交互和范围边界 | 本地 Demo、模拟知识、测试集 |
| PoC | 在获批的一类设备资料上验证检索质量 | 审核资料、检索服务、评测报告 |
| 试点 | 与一条产线/一个班组验证可用性 | 权限、日志、培训、现场反馈 |
| 扩展 | 复制到更多设备/工序 | 知识模板、版本治理、运营机制 |

## 10. 风险与应对

- **错误操作风险：**答案只基于审核资料；无证据拒答；高风险问题升级人工。
- **文档过期：**展示版本和生效状态，建立负责人及更新流程。
- **检索遗漏：**对现场常用问法建测试集，持续检查漏召回和错误命中。
- **权限泄露：**真实部署按用户/班组/工厂控制可检索资料。
- **数据不实：**模拟数据明确标注；真实试点只使用授权资料并获得业务确认。
