# 张凌森个人作品集

静态个人作品集网站，可直接打开 `index.html` 或部署整个 `portfolio` 目录。

## 内容来源与说明

- 个人资料、任职经历、教育信息及运营数据来自简历和用户提供的作品集材料。
- 制造业 SOP 知识助手是个人产品 MVP，设备、工厂和知识条目均为模拟素材；验收结果仅覆盖原型逻辑，不代表真实工厂效果。
- 跨境电商工作台与项目一、项目二来自用户指定的实战项目文件。

## 页面入口

- `index.html`：个人作品集主页
- `index_workbench.html`：跨境电商运营工作台，包含项目一和项目二入口
- `p1p2/`：国际站详情页诊断、竞品拆解 HTML/PDF 和演示素材
- `sop-assistant/index.html`：制造业 SOP 知识助手交互 Demo
- `sop-assistant/面试展示/制造业SOP知识助手_面试汇报.pptx`：项目汇报材料

SOP 产品方案和测试记录见 `sop-assistant/` 目录。
